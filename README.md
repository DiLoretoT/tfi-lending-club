# Predicción de default en préstamos personales de Lending Club

Trabajo Final Integrador de la Diplomatura en Ciencia de Datos y Análisis Avanzado (UTN BA, 2026). Tomás Di Loreto, Grupo 1.

El informe completo está en `TFI_Grupo01_Tomas Di Loreto.pdf`.

## Archivos

- `TFI_LendingClub.ipynb`: notebook con todo el análisis.
- `figuras/`: gráficos que genera el notebook y que usa el informe.
- `TFI_Grupo01_Tomas Di Loreto.pdf`: informe final.
- `requirements.txt`: librerías usadas.
- `datos/`: carpeta donde va el archivo de datos.

## Cómo ejecutarlo

1. Descargar el dataset Lending Club Loan Data de Kaggle (https://www.kaggle.com/datasets/wordsforthewise/lending-club).
2. Copiar el archivo `accepted_2007_to_2018Q4.csv` en la carpeta `datos/`.
3. Instalar las librerías con `pip install -r requirements.txt` (Python 3.12).
4. Abrir el notebook y ejecutar todas las celdas. Tarda unos 15 minutos.
